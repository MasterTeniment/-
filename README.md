قوانین اختصاصی جغرافیا ۲ – درس ۴:

موارد زیر برای فشرده‌سازی و تولید محتوای آموزشی ممنوع هستند:
- «بیشتر بدانیم»
- «بیندیشیم»
- «مطالعه برای انجام فعالیت»
- «مطالعه‌های موردی»
- متن فعالیت‌هایی که درس با آن‌ها آغاز می‌شود
- توضیحات و زیرنویس عکس‌ها و نقشه‌ها
- واژه‌نامه پیوست آخر کتاب

این موارد نباید در استخراج محتوای آموزشی درس ۴ استفاده یا وارد خروجی شوند.
